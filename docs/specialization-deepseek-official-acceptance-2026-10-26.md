## 本轮发现并修复的项目问题

1. 官方不支持 `response_format=json_schema`：官方端点现在直接使用 `json_object`，并在提示中携带 schema；
   其他供应商仍保留 Schema → JSON Object → 普通 JSON 的兼容降级链。
2. PDF 换行或工具读取的跨条款原文被 Gate 错杀：现在会映射回合同中的精确连续原文；只额外容忍行首
   序号的 `3.` / `3、` 差异，不放宽正文内容匹配。离线回放将 68 个候选的结构误判从 46 个降到 0。
3. 同一风险维度下多个专项被错误捆绑：路由改为每个 `check_id` 恰好分配一次，数据检查不再被塞给
   软件权利条款。
4. 模型遗漏专项记录：只基于工具实际读取过的完整条款做一次结构化补录；材料不足时返回
   `needs_material`，不根据目录或常识伪装成已完成。
5. Gate 和摘要输出预算不足：Gate 提高到 1024 token 并限制问题列表长度；摘要提高到 1024 token。
6. 官方长提示词并发不稳定：默认总并发降为 2，配合预留聊天槽保证后台单并发，聊天不被审阅占满。
