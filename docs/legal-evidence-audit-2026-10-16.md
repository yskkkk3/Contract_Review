## 发现并纠正的问题

| 主题 | 会改变结论的内容 |
| --- | --- |
| 研发与成果权属 | 委托发明的专利申请权规则是民法典859条；861条调整技术秘密，含交付前对第三人转让限制。合作开发的默认共有有另约例外；学校付款不当然取得全部权利。 |
| 委托软件与普通作品 | 补入软件条例11条书面约定优先及无约定归受托人的规则。区分软件修改权、合法复制品必要修改与普通作品修改权、改编权，避免建议文本重新产生权利错误。 |
| 中小企业账期 | 先核实付款方类型、供方订约时规模与时间；事业单位与大型企业另约期限的规则不同。付款起算、拖延验收、特别规定不能遗漏，付款期限上限不等于交付至付款的全部历时上限，拖延验收也不等于自动验收合格。 |
| 审计与保证金 | 审计机关结果与普通结算审核不同，核对法定例外；现金不能成为唯一允许的保证方式。 |
| 个人信息 | 保留委托终止返还删除的一般义务，同时补全47条法定保存或技术删除困难的边界。仅存储与继续训练、营销不同。13条履约必要针对个人作为合同一方，不是学校与供应商签约即可替代。 |
| 违约金与不可抗力 | 30%以损失为参照，并非合同总价上限；调整有请求、举证及恶意违约等条件。不可抗力须按实际影响判断，迟延履行后的事件、通知证明、减损和第三人原因不能混用。 |
| 管辖与仲裁 | 国内协议管辖与涉外书面选择中国法院不同；仲裁法2025修订的82条有特定涉外仲裁例外。一裁终局本身不应自动报为风险。 |
| 采购程序及版本 | 纠正采购法47条备案与50条变更的错配，区分实施条例50条公告、51条付款、46条电子档案及采购法42条十五年留存；删除旧代理资格审批责任的过时表述。 |
| 深圳及购买服务 | 原深圳文本以旧版31至33条冒充2019年修正条文，已改为37、38、40条及细则54条，补足批准、预算边界和期限例外。政府购买服务不是所有高校采购服务，一年/三年期限须先判断购买主体和预算等条件。 |

## 审阅链路的修正

新增21组法律主题、53项规则/适用条件/例外核对项。命中主题后，从实际加载的BM25索引取关联文档的完整条文，并保留版本与来源；清单本身不能替代法规证据。相关条文缺失、来源版本未标注或预算不足时，显式报告缺口。现有事实照实采用，只有未给出的事实才待核实。

证据上下文默认7000字符，按完整块装配，超大的块跳过后继续尝试后续块；仅实际展示的正文可以被引用。专家初稿含空列表时也可接受完整性复核，不再因“无风险”而无限重试制造风险。复核和语义质检使用配置中的审阅模型，失败时保留诊断，不能静默认定通过。该方案增加模型调用和延迟，复核超时默认40秒，可配置。

Gate同时接收条款和真实证据正文；未经通过的意见不提前推给前端。仲裁保留同一条款的多项修改建议，整体等级取已核验意见的最高等级，避免一个严重风险被数量规则算成低风险。`end`事件增加可选兼容字段`review_status`；不完整时前端显示“审阅待补查”，不显示绿色整体低风险结论。

入库改为同文档新块成功写入后清理旧块，防止已修正的错误条文仍参与向量召回。只清理本次文档与层级中的过期块，其他文档保留；写入失败不清理。读取`KB_BM25_PATH`配置也同步用于写入。现有运行中的服务仍需重建索引并重新加载才能采用新语料。
