## 行为变化

- 匿名访问受保护 API 返回 401；普通用户访问管理操作返回 403；访问他人合同/账户返回 404。
- 改密或改名成功后，目标账户需要重新登录；禁用同时撤销令牌。
- 被引用合同删除返回 409，需要先删除对应会话；运行中的审阅会话不能直接删除。
- 失败或取消的重审保留旧结果；历史查询优先返回最近一次成功任务。新的有效结果成功提交后替换旧结果。
- 文件清理如果在数据库成功删除后失败，会记录日志并可能留下未引用文件，不会把已失败的数据库删除变成合同文件丢失。

未执行任何现有数据清理或数据库迁移；未修改 `.env`；未改动用户原有的 `backend/run_dev.py` 工作区修改；未提交或推送。
